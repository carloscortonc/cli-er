cli-erAdvanced type-safe CLI builder

Build modular, well-structured CLI applications using a definition object. Includes help generation, routing, hooks, plugins, and more.

Get Started
View on GitHub
Playground
📖

Help generation

Automatically generates scoped help for all commands and namespaces, with support for parent-scope options and custom templates.

🗂️

Routing

Resolves command handlers via a predictable folder-structure strategy, keeping large CLIs clean and maintainable.

🔗

Lifecycle hooks & Plugins

Execute code on beforeParse, afterParse, beforeExecute and afterExecute events. Bundle hooks into reusable plugins.

⚙️

Config file & Env vars

Read options from config files (JSON, INI, …) and from environment variables matching a prefix — no manual wiring required.

🌐

Intl support

Override any library message via CliOptions.messages to build fully internationalized CLIs.

🔷

TypeScript-first

Typed command and namespace options via Cli.defineCommand / Cli.defineNamespace helper utilities.
