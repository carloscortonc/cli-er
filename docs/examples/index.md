# Examples

Explore these examples to see `cli-er` in action. Each example is available in the [`examples/`](https://github.com/carloscortonc/cli-er/tree/develop/examples) directory of the repository.

| Example | Description |
|---|---|
| [Basic (config)](/examples/basic) | Minimal CLI reading options from a config file |
| [Docker](/examples/docker) | Docker-like multi-level namespace/command CLI — try it in the [Playground](https://carloscortonc.github.io/cli-er/?cmd=docker) |
| [Webpack CLI](/examples/webpack-cli) | Single root-command CLI, mimicking webpack — try it in the [Playground](https://carloscortonc.github.io/cli-er/?cmd=webpack) |
| [TypeScript CLI](/examples/ts-cli) | Full TypeScript CLI with typed options |
| [Hooks](/examples/hooks) | Lifecycle hooks: authentication check before execution |
| [Plugin](/examples/plugin) | Reusable plugin encapsulating hooks |
| [Intl](/examples/intl-cli) | Internationalized messages via `CliOptions.messages` |
| [Bash Completion](/examples/bash-completion) | Generated bash-completion script usage |
| [Debug Logger](/examples/debug-logger) | Static `Cli.debug()` logger |
| [Jest CLI](https://github.com/carloscortonc/cli-er/tree/develop/examples/jest-cli) | Positional arguments, mimicking jest |
| [Tail](https://github.com/carloscortonc/cli-er/tree/develop/examples/tail) | Reading option values from stdin |
| [Custom Option Parser](https://github.com/carloscortonc/cli-er/tree/develop/examples/custom-option-parser) | Defining a fully custom option parser |
