# Example: Webpack CLI

Source: [`examples/webpack-cli/`](https://github.com/carloscortonc/cli-er/tree/develop/examples/webpack-cli)

Mimics the webpack CLI with a single root command (`rootCommand: "webpack"`). Showcases:
- `CliOptions.rootCommand` as a string to define the default command
- Rich option types: `boolean`, `string`, `list`, `number`
- Positional arguments

Try it live in the **[Playground →](https://carloscortonc.github.io/cli-er/?cmd=webpack)**
